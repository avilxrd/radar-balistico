# Jogo 5 - Radar Balístico
Artur Fardin Correa, Miguel Avila de Oliveira e Nicolas Monteiro Longo.

## Sobre o Jogo
O jogador controla uma aeronave cercada de objetos voadores não identificados. O objetivo 
é abater todos os inimigos sem acertar os aliados e civis. O radar não diferencia uma aeronave inimiga de uma aeronave civil, para concluir seu objetivo, o jogador precisa contar com ajuda da cabine de controle, que saberá as posições dos inimigos.
